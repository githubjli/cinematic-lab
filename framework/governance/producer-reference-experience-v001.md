# 制片参考经验 v001

本文件保存经用户认可、可在新项目中检索的制片方法。经验按任务采用并持续回写，不因认可而自动获得生成效果、效率或成本验证。

## PR-001 管理完整、动作具体、提交精简

记录日期：2026-11-13。用户已认可纳入制片参考。来源：[案例031与032比较](../../analysis/032/v001/comparison-with-031.md)、PM-031与PM-032。证据成熟度S1，尚无本地生成对照。

### 1. 用《惊夜》的结构管理生产

按拆场、场景/人物/道具母版、参考职责、对白、镜头合同、候选审查与后期交接组织生产。每份输入说明负责什么，每个镜头说明初态、叙事任务、末态与验收；保留版本与选片理由。

适用：多人、多场景、对白和关键道具驱动的电影、短剧等。简单任务可裁剪字段。产物采用[生产包](../templates/production-package-v001/README.md)及[母版与镜头合同](../templates/master-asset-contract-v001.md)。

### 2. 用《淄水渡》的思路设计复杂动作

先定义位置、支撑、连接、持握和状态变化，再安排摄影与生成。写清物件两端接到谁、谁支撑谁、怎样换手、受力或断裂如何发生，以及动作后物件去了哪里；区分陆上、水面、水下等环境状态。

适用：救援、动作、机械运动、人与环境/物件交互。使用[事件与连接关系合同](../templates/event-and-attachment-contract-v001.md)。存在几何或可达性风险时，先用简图或三维白模预演；预演通过不代表后续生成自动符合。

### 3. 提交前做减法

先做动作与对白计时、必要预演及冲突核对，再按所选模型能力形成提交文本。管理合同保留完整信息；每次生成只带本镜需要的资产职责、关键动作、空间约束、声音和末态。按风险决定拆镜，避免短时长塞入过多动作、对白或参考。

精简不能删掉身份、因果和交接所必需的约束。明确全片、场次、镜头规则的适用范围与覆盖关系，消除方向、参数和表演强度冲突。准确保存实际提交原文、输入哈希和上传顺序，不以内部合同冒充实际提交。

### 项目采用与反馈

新项目在制片入口判断本经验哪些部分适用，记录采用/裁剪原因；生成前核对上述三项，复杂交互追加连接关系合同。工具按现有选型表匹配，不绑定案例平台，也不据此自动安装或付费调用。

输出后分别审查身份、空间、物件交互、表演、声音和接戏，记录时间码、候选数、可用秒数、人工修改与费用。失败先判断属于母版、动作设计、提交冲突、工具能力还是后期问题，再修改对应层。保留基线与失败候选；经对照验证后按维度更新PM-031/PM-032成熟度和本文件后续版本。
