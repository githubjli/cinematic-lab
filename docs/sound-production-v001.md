# AI影视声音制作经验 v001

更新日期：2026-10-14。来源为案例019及既有影视流程归纳。案例019侧重音效库、语义检索、动作拟音和缺失声音生成；以下扩展为可执行声音流程，不冒充视频中的原始提示词或已验证参数。

## 一条可复用的声音流程

### 1. 先做声音事件表

不要先打开音效库盲搜。逐镜记录：

| 字段 | 内容 |
|---|---|
| 镜头/时间码 | 声音开始、峰值、结束和允许的提前/拖尾 |
| 层级 | 对白、环境底、动作拟音、设计音效、音乐、静默 |
| 声源与动作 | 谁/什么，以什么方式发声 |
| 材质 | 金属、木、布、玻璃、砂石、水等 |
| 空间 | 室内/室外、大小、反射、开阔/封闭 |
| 听点 | 远近、方向、主观/客观、镜内/镜外 |
| 强度和演化 | 轻/重、慢/快、由远到近、渐强/骤停 |
| 同步 | 硬同步、软同步、反向同步或刻意静默 |
| 来源策略 | 库检索、现场拟音、合成、AI生成或多层组合 |
| 状态 | 候选、采用、需重做、静态已查、连续已听 |

### 2. 按成本和可控性选择来源

常见真实声音优先查授权明确的库；需要精确触感时录拟音；不可能录到或需要风格化时再做合成/生成。生成不应取代所有库素材，因为常用撞击、门、脚步和环境底往往需要稳定版本、多个透视及连续性。

推荐顺序：检索已有资产→编辑/分层→现场拟音→程序合成→AI生成缺口。每一步均保留候选。

### 3. 用可听见的属性写检索词或生成描述

模板：

`[声源]＋[具体动作]＋[材质/接触]＋[空间]＋[距离/方向]＋[力度/速度]＋[时长/演化]＋[需要避免的内容]`

示例：`空旷混凝土走廊里，一扇沉重金属防火门从半开缓慢关闭；听点距门约五米，铰链轻微摩擦，末端低沉扣合，约3秒；无音乐、无人声、无夸张电影冲击。`

生成多个变化时只改一个轴，例如距离、力度或材质，便于比较。准确提交原文、模型、版本、种子、时长和输出哈希全部保存。

### 4. 分层制作，不要求一条声音包办全部

一个动作通常可拆成：起动/接触瞬态、主体摩擦或运动、末端撞击、空间尾音。环境则拆成稳定底噪、间歇事件和远景活动。各层可独立调整；AI生成的“一整条成品声”若无法编辑，应谨慎采用。

### 5. 声音跟随画面事件

- 硬同步：撞击、脚落地、按钮、门扣合等，瞬态对齐动作接触帧。
- 软同步：环境、机械持续声、风和音乐按段落能量变化。
- 预响/拖尾：声音可先于画面建立空间，也可跨切点维持连续性。
- 视角变化：远景减少近距离细节，遮挡时改变高频和直达声比例。
- 静默：明确写入事件表和时间范围，避免被误判为漏音。

### 6. 编辑与混音

裁掉无用前后段，做短淡入淡出防爆音；检查循环接缝和相位。对白优先时，为音乐和环境留出频率与动态空间。不要把归一化当混音完成；输出前检查削波、真峰值、整体响度、左右声道、单声道兼容及不同播放设备。具体响度目标按交付平台确定，未知时不写死数值。

### 7. 听审

至少完成三遍：

1. 只听声音：噪声、剪切、重复、突兀尾音、声像和动态。
2. 声画一起：动作同步、空间视角、跨镜连续性和叙事重点。
3. 多设备：耳机、普通扬声器、手机小音量；对白必须可懂，低频不能成为唯一信息。

审查状态分开记录：文件存在、技术可解码、单条听审通过、声画同步通过、整片混音通过。

## 资产管理经验

命名建议包含`类别_声源_动作_材质_空间_透视_版本`。同时保存原始文件、编辑副本、来源URL/授权、采集或生成日期、采样率/声道、描述、使用镜头和审查结果。

去重分三层：文件哈希去完全重复；音频指纹找重新编码版本；人工听审判断相似内容是否仍有不同透视/力度价值。任何自动去重先输出候选清单，不直接删除原件。

## 工具映射

| 任务 | 先考虑 | 边界 |
|---|---|---|
| 探测、裁切、转码、混音和响度分析 | FFmpeg | 不作语义或审美判断 |
| 批量编排声音与视频 | MoviePy/FFmpeg | 复杂混音仍需听审 |
| 人工时间线和关键帧 | Kdenlive或Shotcut | 保存工程、素材路径和版本 |
| 语义检索/生成工作台 | 案例019的大羽音效库作为候选 | 未确认开源、生成模型、费用或素材授权范围 |
| 代码视频声音编排 | Remotion＋FFmpeg | 浏览器时间线不代替最终响度和音频质量检查 |

准备声音提示词、上传素材或整理方案不等于授权调用付费生成。使用第三方音效时，软件许可、单条素材许可、人物声音权利和发布平台规则分别核对。
