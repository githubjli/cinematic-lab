# AI影视工具选型表 v001

更新与官方来源核对日期：2026-10-13。用途：cinematic-lab出现相关需求时，优先查本表并评估匹配度。优先级是本项目的选型建议，不是行业排名或默认安装授权。

优先：该类需求出现时首先评估；条件优先：满足任务、硬件或许可条件后评估；专项：特定研究/规模化需求再引入。未核验本机GPU、显存、完整安装状态；除已使用的FFmpeg解码器和已保存的OpenMontage源码，其他工具没有在本项目中验证运行。

## 功能与需求匹配

| 工具/官方来源 | 定位与环节 | 优先考虑的需求 | 典型输入 → 输出 | 本项目优先级 | 适用边界与主要限制 |
|---|---|---|---|---|---|
| [Promptfoo](https://github.com/promptfoo/promptfoo) | 提示词/模型评测；P0/P1/P7 | 比较剧本分析、分镜生成、格式遵循的提示词版本 | 提示词、测试样例、模型配置、断言 → 对照结果和评测报告 | 优先：提示词比较 | 影视质量指标需自行设计；文本评分不能证明视频动作正确；调用模型可能收费 |
| [DSPy](https://github.com/stanfordnlp/dspy) | 语言模型程序与优化；P0/P1/P7 | 稳定批量把故事转换成分镜、资产清单和镜头要求 | 任务签名、样例、模块、指标 → 优化后的语言模型程序 | 专项：重复任务 | 需要可信样例与指标；小型一次性任务不一定值得引入；优化会增加模型调用 |
| [ComfyUI](https://github.com/Comfy-Org/ComfyUI) | 节点式生成工作流；P2/P4/P7 | 保存多输入、多模型、参考约束和生成参数 | 模型、图像、文本、节点图 → 生成素材与工作流记录 | 条件优先：可复现生成 | 是工作流运行环境，不是单一视频模型；节点/模型兼容性分别核验；部分节点调用云服务 |
| [Wan2.2](https://github.com/Wan-Video/Wan2.2) | 视频生成模型；P4 | 本地文生视频、图生视频候选实验 | 文本或图像、权重、参数 → 视频候选 | 条件优先：本地生成 | 配置和显存随模型规格、分辨率、时长与卸载策略变化；不保证身份、物理和跨镜头连续性 |
| [ControlNet](https://github.com/lllyasviel/ControlNet) | 图像条件控制；P2/P3 | 从姿态、深度、边缘约束关键帧和分镜图 | 控制图、文本、兼容基础模型 → 受约束图像 | 条件优先：关键帧控制 | 主要是图像控制；不能直接视为通用视频走位控制器；不同基础模型需要匹配版本 |
| [Kdenlive](https://github.com/KDE/kdenlive) | 人工时间线剪辑；P6 | 多镜头叙事剪辑、声音调整与成片交付 | 视频、图像、音频、字幕 → 可编辑工程和成片 | 优先：人工剪辑 | GUI操作与人工判断占主导；不负责AI镜头生成；交接时保存工程与素材路径 |
| [Shotcut](https://github.com/mltframework/shotcut) | 人工视频编辑；P6 | 直接裁切、拼接、滤镜与音频处理 | 素材、时间线 → 工程和成片 | 备选：人工剪辑 | 与Kdenlive按操作习惯和功能匹配二选一；无需同时部署两套；不负责生成内容 |
| [MoviePy](https://github.com/Zulko/moviepy) | Python视频编辑库；P6/P7 | 按规则批量拼接、叠字、裁切、处理音轨 | Python脚本、素材、时间参数 → 视频与处理脚本 | 优先：Python自动合成 | 长片/复杂合成要检查性能；版本间API有差异；文字排版与电影节奏仍需专门设计 |
| [FFmpeg](https://ffmpeg.org/about.html) | 底层媒体处理；P4/P5/P6/P7 | 探测、抽帧、转码、截取、滤镜、混音、编码 | 媒体与命令参数 → 媒体、帧图、技术报告 | 优先：基础处理 | 不作语义或审美判断；编码、帧率、色彩和音频参数需显式记录；避免覆盖原件 |
| [PySceneDetect](https://github.com/Breakthrough/PySceneDetect) | 镜头边界检测；P1/P6 | 自动建立长参考片镜头索引、剪辑节奏统计 | 视频、检测器和阈值 → 时间码清单、镜头片段 | 优先：参考片拆镜 | 闪光、字幕和剧烈运动可能误检；转场可能漏检；镜头边界需人工复核，不能替代内容分析 |
| [VBench](https://github.com/Vchitect/VBench) | 视频生成质量评测；P4/审查 | 比较主体一致性、运动平滑、闪烁与视觉质量等维度 | 视频、提示词/元数据、评测模型 → 分项指标 | 专项：批量候选评测 | 多个版本/指标要求不同；评分不能代替叙事、表演和声音审查；必须记录版本和所用维度 |
| [ImageReward](https://github.com/zai-org/ImageReward) | 文生图人类偏好评估；P2/P3/审查 | 辅助排序同一要求下的分镜/关键帧候选 | 提示词、候选图、权重 → 分数/排序 | 专项：图像候选筛选 | 偏好模型有数据偏差；分数不是普适审美标准；不能评估视频连续运动与剪辑 |
| [Remotion](https://github.com/remotion-dev/remotion) | React/TypeScript代码视频；P3/P6/P7 | 产品发布片、动态图形、字幕、数据驱动模板及批量变体 | 组件、素材、数据、帧时间线 → 可预览合成与渲染视频 | 条件优先：代码动效 | 需要代码与设计能力；浏览器渲染消耗资源；不是写实镜头生成模型；采用专门许可 |
| [OpenMontage](https://github.com/calesthio/OpenMontage) | 多阶段制作与工具编排；P0–P7 | 研究参考→脚本→场景→素材→合成的交接与生产记录 | 创意/参考、配置、工具与素材 → 生产文件、资产和渲染产物 | 专项：端到端流程研究 | 已保存源码但未运行；可用能力取决于依赖与服务；不能从“一句话”宣传推断完全自动或免费 |

上述影视用途和优先级为研究者根据官方功能做的项目映射，尚未独立验证。产品本身的功能与源码定位以每行官方来源为依据。

## 需求出现时的优先路线

| 需求触发 | 先考虑 | 配套/备选 | 本项目验收重点 |
|---|---|---|---|
| 拆解参考片、统计镜头 | FFmpeg + PySceneDetect | 人工时间码复核 | 镜头边界正确，声音/运动连续审查另记 |
| 比较分镜提示词版本 | Promptfoo | 数据充分后DSPy | 相同测试集，结构、遗漏、叙事逻辑和调用成本 |
| 可复现的本地AI镜头生成 | ComfyUI + Wan2.2 | 关键帧适配ControlNet | 输入哈希、上传顺序、节点图、原文、参数、全部候选 |
| 让关键帧符合姿态/构图 | ControlNet + 兼容图像模型 | 二维路线图、三维白模预演 | 条件匹配、身份、姿态和空间关系 |
| 多镜头叙事剪辑 | Kdenlive | Shotcut | 节奏、连续性、声音、工程可编辑和素材可追溯 |
| 批量裁切、混音、转码 | FFmpeg | MoviePy负责复杂脚本编排 | 帧率、色彩、音画同步、时长和编码 |
| 产品片、代码动效、模板变体 | Remotion，先核对许可 | MoviePy/FFmpeg | 文字排版、节奏、音效、渲染稳定性 |
| 大量视频候选质量比较 | VBench | 人工连续审查 | 按维度对比，不以总分替代看片 |
| 大量关键帧候选排序 | ImageReward | 人工按视觉规则复核 | 同一提示词下比较，保存分数与人工取舍 |
| 研究制作流程如何封装 | 已下载OpenMontage源码 | 对照本项目统一分析框架 | 步骤依赖、文件交接、记录完整性与质量关口 |

## 执行与记录约定
