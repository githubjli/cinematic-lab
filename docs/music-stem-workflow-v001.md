# 音乐分轨制作与使用流程 v001

更新日期：2026-10-19。来源为案例025及本地声音制作流程归纳。此文档只整理方法，没有授权下载商业音乐或运行分离模型。

## 选轨顺序

1. 优先使用明确授权且提供原生stem的曲目。
2. 没有stem但有处理权时，使用Demucs或UVR生成候选分轨。
3. 只需要降低对白冲突时，先尝试自动化、EQ和动态闪避，不必为了一个问题分完整首歌。
4. 需要完全可控的节奏和音色时，改用可编辑工程、MIDI或重新配乐。

## 标准工作流

`授权检查 → 无损母带入库 → 原生/AI分轨 → 同起点导入 → solo听审 → 功能标签 → 镜头事件表 → 编排与自动化 → 总线混音 → 多设备验收`

建议目录：

```text
music/<track-id>/
  source/          # 原母带与授权凭证
  stems-native/    # 原生stem，不覆盖
  stems-ai/<model-version>/
  edits/<edit-id>/
  mix/
  manifest.json
```

`manifest.json`至少记录来源、许可、母带哈希、分轨类型、工具和权重、准确命令、采样率、轨道零点、每轨哈希、使用镜头、增益/静音自动化和听审状态。

## 编排原则

- 用Percussion建立节拍，用Pads维持连续空间，用Bass建立重量，用Bells/FX强调少数事件。
- 镜头转折前可先抽掉一层，转折时再恢复，比持续增加响度更清楚。
- 对白出现时优先减少冲突轨的编配或电平，再考虑大幅EQ。
- 音乐跨切点可维持空间连续；动作硬同步交给独立SFX，不强迫配乐承担每个动作点。
- 保留有意静默，登记开始和结束时间，避免后续误补。

## 本地工具优先级

| 需求 | 优先工具 | 说明 |
|---|---|---|
| Windows图形界面、多模型比较 | Ultimate Vocal Remover GUI | 适合人工试不同模型；保存模型与设置 |
| 脚本批处理、四轨/六轨 | Demucs | 可CPU/GPU；适合接入资产流水线 |
| 裁切、格式统一、合成、响度检查 | FFmpeg | 不负责源分离审美判断 |
| 人工编排和自动化 | Kdenlive、Shotcut或DAW | 视频剪辑器能做基础混音，复杂音乐建议DAW |

## 失败模式

- 把原生stem与AI估计stem混为一谈。
- 从有损MP3反复分离、转码和导出，累积伪影。
- 单轨听起来“干净”就通过，没有检查全部重组后的相位和电平。
- 只下载鼓轨或氛围轨，却忽略其许可仍继承原曲条款。
- 为了贴每个切点把音乐切得过碎，失去乐句和呼吸。
- 用低频制造情绪，但手机端几乎听不到。

最终状态分为：文件存在、技术通过、单轨听审通过、重组通过、声画通过、整片混音通过。状态不可互相替代。
