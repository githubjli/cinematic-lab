# 数学AI与可视化工具选型 v002

更新日期：2026-10-14。在v001基础上新增Anatomy的技术/科学机制解释路线。所有工具仍需按实际题型、许可和运行条件核验。

| 工具 | 主要用途 | 优先使用条件 | 核验边界 |
|---|---|---|---|
| Qwen2.5-Math / DeepSeek-Math | 数学题推理与讲解候选 | 需要数学专用模型比较 | 答案和推理必须独立核验，模型/代码许可分别检查 |
| SymPy | 符号计算 | 化简、方程、微积分、矩阵 | 显式定义域、分支和假设；计算不等于教学证明 |
| SageMath | 综合数学计算 | SymPy不足或涉及代数、数论、组合等综合领域 | 环境较重；组件许可分别核对 |
| Manim Community | 公式、几何、坐标和连续数学变换动画 | 数学讲解动画首先考虑 | 数学对象、标注、比例和连续运动逐项检查 |
| 3b1b/manim | 原作者动画生态研究 | 需要对应实现时 | 与社区版API不完全兼容 |
| Lean 4＋mathlib4 | 形式化证明 | 需要机器检查定理时 | 原题与形式化陈述必须一致；检查占位证明和新增公理 |
| Anatomy | 机械/仪器/技术系统的交互式等距原理图 | 概念可表达为真实部件及因果机构时 | 不是坐标图、CAD或仿真；真实数量和物理规律另核验；3D为beta |
| Remotion | 数学/科学片的字幕、节奏和模板化包装 | 需要成片、批量版本或时间编排 | 数学计算与原理正确性由上游工具/人工负责 |

推荐路线按内容分流：公式和函数→SymPy/SageMath核验＋Manim；严格证明→Lean；机械机构或可实体化系统→事实来源＋Anatomy；最终成片→Remotion或剪辑工具＋FFmpeg。Anatomy可以把缓存、连接池等抽象系统映射成机械装置，但隐喻不得替代真实技术说明。
