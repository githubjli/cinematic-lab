# 国际MG高质量门禁与独立审评 v001

更新日期：2026-10-19。目标是把“高端商业/获奖入围级”变成制作过程中的严格基准。此量表不能保证任何奖项结果；正式投稿以具体奖项当届规则与真人评委为准。

### 内部门槛

- D3最难镜头起：加权总分至少85/100，每项至少75/100。
- 最终母版目标：加权总分至少90/100，概念、视觉系统、动画工艺三项至少85/100；只标记为“奖项投递候选”。
- 至少两名独立盲评者加一名人类创意/动效负责人；取中位数，不因单个高分放行，评分分歧超过10分时重新校准。
- 与同类别8–15个真实高水平参考做并排盲评；必须能明确说出本片的独特机制。
- 分数只是门禁。正式“入围”只能由奖项主办方确认。

## 一票否决

- 未授权音乐、字体、影像、Logo、模型权重或无法说明来源的关键资产。
- 错误品牌名、事实、年份、字幕，或AI生成的不可接受乱码。
- 核心画面与参考作品构图/运动高度近似，无法证明独立设计。
- 闪帧、黑帧、掉帧、音画漂移、削波、错误分辨率/帧率/色彩空间。
- 关键信息在目标屏幕不可读，或未满足投稿的字幕、片长、匿名化等规则。

## 独立subagent审评协议

制作Agent和评审subagent严格分离。评审只接收：

1. 当前候选文件及SHA256；
2. 原始brief与目标受众；
3. 本量表、目标类别和技术规格；
4. 固定参考集，但不提供制作Agent的提示词、解释、选型理由、历史评分或自评。

评审输出固定为：

```json
{
  "candidate_sha256": "...",
  "hard_fail": false,
  "scores": {"concept": 0, "originality": 0, "direction": 0},
  "weighted_total": 0,
  "timecoded_findings": [{"time": "00:00.000", "severity": "blocker", "evidence": "...", "fix_goal": "..."}],
  "top_strengths": [],
  "revision_order": [],
  "verdict": "reject|revise|pass"
}
```

评审不提供具体画面替代方案，不直接修改代码，以免把自己的偏好变成第二套导演方案。制作Agent收到的是按严重度排序的`fix_goal`。返修后使用新哈希重新盲审，并做回归检查：修复处是否改善、其他段落是否退化、总体概念是否仍清晰。

## 防止评分失真

- 先用3个锚点校准：约60分模板片、约80分成熟商业片、90分候选级作品；记录选择理由。
- 参考作品名称在打分时隐藏，避免品牌和奖项光环。
- 每轮换序，隐藏上轮分数；评审先写证据，再给分。
- 至少保留一个隐藏维度，例如“第一遍观看后能否复述核心信息”，防止只针对公开量表优化。
- 两次迭代后若总分提高但核心概念变弱，以证据为准退回，不追逐平均分。
