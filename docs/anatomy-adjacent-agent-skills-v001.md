## 推荐借鉴顺序

1. 继续保留Anatomy作为机械原理图基线，不再并行安装同类低热项目。
2. 若需要严谨的流程/系统图，优先研究Archify的中间表示、验证和交付回执。
3. 若需要更强的编辑设计规范，参考diagram-design的类型选择、删减规则和静态可读性。
4. 若需要直接输出动画流程图，再比较SeeCode与DashMotion。
5. 当前金耐力主体仍优先Blender、授权素材、剪辑和声音；上述Skill不进入主体制作依赖。
