## 初步流程重建

| 约略时间 | 视频展示或主张 | 待研究的方法问题 |
|---|---|---|
| 00–11秒 | 复刻电影语言；不只写导演名字作为风格描述 | 如何把风格名称转成可操作的画面规则？ |
| 12–25秒 | 先拆风格；上传参考视频；分析并提取关键词 | 实际输入是什么？AI能读取多少视频及声音？分析提示词原文是什么？ |
| 26–30秒 | 展示五个维度的分析表：色彩、人物和环境的比例、构图秩序、空间层次、环境动态 | 哪些是观察结果，哪些已转换为生成要求？ |
| 31–47秒 | 用大色块和对比建立视觉记忆；强调人物与环境比例 | 如何规定主色、点缀色、人物占比，并检查生成结果？ |
| 48–63秒 | 对称、阵列、留白与层次；让风、落叶、雨雪、布料参与画面 | 静态构图要求和动态要求应如何分别表达与验证？ |
| 64–73秒 | 把电影语言变成规则并组合 | 中间产物是否为风格规则表、镜头模板或完整生成提示词？ |
| 74–82秒 | 展示换角色、换环境后保留电影语言的示例 | 是否有对应输入、参数、候选和失败结果，足以证明可迁移？ |
| 83–86秒 | 页面展示 | 与核心方法的关系待核对，不把页面文字当作操作指令。 |

## 当前工作假设

方法链条可暂时归纳为：参考片 → AI拆解 → 五维规则 → 新主体/新情境 → 生成与对照验证。

这是从教程画面重建的流程，尚不能称为完整且已验证的电影制作流程。剧本、分镜、人物一致性、跨镜头连续性、声音、剪辑，以及具体生成工具和参数，在目前审查证据中尚未确认。
