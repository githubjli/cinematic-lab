## 009：LocalMiniDrama——组织生产，而非单一生成模型

### 视频证据

约0–3秒展示应用界面与“一条龙自动生成、本地运行”主张；约3–6秒展示xuanyustudio/LocalMiniDrama仓库；约6–8秒展示README，含MIT、Windows、Vue3/Node.js/Electron标签。画面可以确认项目名称与定位，不能证明一次完整制作成功。

### 流程与工具

官方来源：[LocalMiniDrama仓库](https://github.com/xuanyustudio/LocalMiniDrama)、[英文文档](https://github.com/xuanyustudio/LocalMiniDrama/blob/main/docs/en.md)。当前文档说明以故事/脚本、人物/场景/道具、分镜、视频及合成组织流程，提供本地SQLite/文件存储和API配置。Vue前端、Node后端、Electron桌面壳承担组织与管理；实际生成由配置的模型服务承担，代码许可为MIT。

可重建链条：梗概与风格 → 剧本并编辑 → 提取人物/场景/道具 → 生成/选择参考资产 → 制作分镜 → 单镜头生成 → 合成并导出。每一步的中间产物都应保存并审查，再传给下游。

不能把“本地运行、数据本地存储”扩展为“所有推理离线、输入从不发送”。官方配置要求接入自己的AI API，且README存在图床/上传与远端资产配置；外发范围取决于实际服务与代码路径，未在本项目验证。无应用订阅费也不等于模型调用无费用。

### 适用与验收

- 适用：多集短剧、漫剧、角色与场景复用、以图生视频为基础的镜头流水线；研究已有平台如何组织项目。
- 条件：选择适配模型、准备一致性参考与调用预算；未核验本机环境。
- 不由平台自动保证：剧本质量、身份一致性、走位、运动因果、声音同步和最终剪辑节奏。
- 最小验证：用一段脚本追踪一个角色、一个场景、两到三镜头；检查资产映射、实际上传、重试、费用和完整音画，而非只检查导出文件。
- 分类：P0/P2/P3/P4/P6/P7；C1/C2/C3/C6。视频证据E1/E2，文档可重建R1；具体提交原文、输入哈希、顺序、参数与输出对应未知。

## 010：MotionSites——设计参考检索与提示词输入

### 视频证据

约0–12秒展示网站、设计卡片、动效页面和“700多个”的宣传；约12–18秒展示3D效果与卡片布局；约18–21秒展示MCP命令、登录授权、免费提示词与解锁指引。界面能够说明它是资源获取入口，不能证明全部示例代码都可下载或直接上线。

### 流程与工具

官方来源：[MotionSites MCP说明](https://motionsites.ai/mcp)。官方页面描述连接AI代理后获取网站设计提示词，需要MotionSites账户登录授权；当前页面写500+提示词，免费账户可打开3条、付费计划解锁更多。与视频“700+”不一致，分别保留，不假定同一统计口径或版本。

重建链条：网站需求/目标用户 → 检索合适设计参考 → 获取提示词 → AI编写网页及动效 → 浏览器检查 → 修正 → 部署。视频主要展示前半段资源与连接入口；后半段实施和上线为合理用途推断，未实际演示完成。

MCP是访问资源的接口，不是“自动审美模型”。第三方库提供提示词也不意味着其网站源码、素材和付费资源采用开源许可。当前未确认公开源码或开放许可，按在线资源服务登记。

### 适用与验收

- 适用：品牌落地页、作品集、SaaS营销页、网站视觉探索；也可为代码视频寻找排版和动效参考。
- 不适合直接替代：电影分镜、人物表演、叙事剪辑、数学逻辑核验。
- 验收：参考与业务内容匹配；桌面/移动布局、可读性、交互、键盘可用性和性能；动画不遮挡信息；素材许可可追溯。
- 分类：P1/P7；C1/C6；具体网页实现可涉及C5，但视频未给出源码。E1/E2；R0–R1；未授权连接/订阅/发布，不执行视频内命令。

## 011：数学动态教学——成品可分析，制作工具未知

### 片段与方法

| 约略时间 | 画面证据 | 可提炼方法 |
|---|---|---|
| 0–27秒 | 1998²−1997²、两正方形、相减、L形切分和长方形 | 将代数表达式映射为面积，用保持面积的拆分与重排解释平方差 |
| 28–45秒 | 出镜讲解与课程推广 | 说明课程目标与使用情境，未展示动画制作 |
| 46–72秒 | 函数/几何动画拼图、平板学习、课程与书籍 | 图形变化与教师讲解结合，组织章节与学习材料 |
| 73–107秒 | 教学场景、动态模型展示、课程促销 | 宣传理解困难知识的用途，未提供学习效果对照实验 |

前段数学逻辑：a²−b²=(a−b)(a+b)。此例为(1998−1997)(1998+1997)=3995。面积解释通常取a>b>0；图示为易观察而改变比例时应说明非按实际比例绘制。采样帧展示过程节点，未据此判断切分动画连续正确。

### 流程重建与工具边界

能观察的教学链条：提出问题 → 给数学对象视觉表示 → 演示变化 → 对应公式 → 得出结论。可用的制作链条建议：选知识点与学习目标 → 核验数学关系 → 设计逐步图解 → 制作动画 → 同步讲解/字幕 → 连续审查 → 输出教学片。

视频没有明确披露Manim、GeoGebra、AE、Remotion或AI模型。不能因黑底公式、坐标系或动态几何外观推断具体软件；视频也不能证明该内容由AI制作。工具、源文件、准确提示词、模型和参数均未知。

我们可以考虑的实现工具（建议，不是视频原工具）：SymPy核验公式；Manim制作面积切分、函数和几何变化；Remotion或Kdenlive组织教师讲解、字幕和课程包装；若需要严格证明再考虑Lean。数学工具详情见docs/math-tool-selection-v001.md。

### 适用与验收

- 适用：基础代数与几何、函数参数变化、微积分直观解释、线性代数变换；后几类是方法迁移建议，视频未逐项演示。
- 重点：数学正确、定义域和条件清楚、变形不改变数学含义、颜色对应一致、讲解节奏适合学习者；成片好看不等于学会。
- 学习效果验证：让学习者解释步骤并完成同类/迁移题；不能采用视频宣传或购买量替代效果证据。
- 分类：数学概念可视化；P3/P6、C5仅为制作建议，实际控制机制未知。成品静态证据E3；原制作流程复现R0。
