分析日期：2026-10-19。输入`stodownload (20).mp4`，SHA256为`1B33463925E74B1198195AF6FAC8F481C659C549BFE40BE1424DB6C2F9AE44E1`。文件约248.99秒、1280×720、24fps、H.264/AAC。已每2秒静态采样；尚未完成逐字转录、连续运动、完整声音和独立复现。

视频讨论不用预制Skill或既有案例，直接要求一个编码Agent制作MG视频，并用三种由浅入深的任务观察能力。视频将结果归因于“Claude Code / Opus 5.5”，但没有保存完整会话、工具调用、源码快照、准确参数与全部候选，本项目只记录可见流程和可迁移方法，不把宣传结论视为模型能力验证。

## 视频明确展示的流程

### 三轮任务，由浅入深

1. **概念短片**：以Anthropic理念和发展史为题，要求包含音效和音乐，允许Agent选择工具与技术，追求最佳效果，同时明确不使用已有Skill、不参考此前视频或文章。主Agent先写全片时间表，再制作/渲染。
2. **纯代码音乐MV**：输入音乐WAV与`lyrics.txt`，生成约59秒纯代码MV；第二轮要求借鉴P5R的MAD形式，并下载官方宣传片作为素材。
3. **多风格Demo集**：整理国际MG风格体系，围绕15种风格制作共22支短Demo，视频称剪辑中使用约1,915个镜头/素材单元，从中选取66个。风格包括平面矢量、线条、几何、形变、3D、等轴2.5D、液态、颗粒、逐帧手绘、拼贴、Synthwave、蒸汽波、像素、故障、赛博HUD，并与若干中文短视频常见风格对照。

第三项更像“风格能力测试集”，不能自动证明完整成片的概念、叙事和声音同样优秀。

### 视频强调的两个技巧

1. **把质量标尺写高**：可见英文提示片段要求“award-shortlist / high-end commercial quality”，并将模板化结果判为失败。视频用5–10分标尺解释：6分为模板/剪映水平，7分为专业，8分为高端广告公司，9分为获奖入围，10分为世界顶级。
2. **独立subagent盲审**：制作Agent负责写代码/出片；审评subagent只看成片与评审标准，不包含主Agent上下文。可见量表要求风格还原、创意与独特、动效工艺、设计与排版、质感与细节、声音同步、技术规格等单项不低于7.5。视频称首轮22支Demo平均约6.95，修改两轮后画面分别显示7.80和7.81，存在0.01的显示差异。

视频还称第一项未用Remotion或现成视频素材，由Agent自写WebGL渲染器，并用Python计算配乐/合唱与约30类音效。这些是作者展示的实现说明；未取得源码、音频分轨或环境锁文件，尚不能复现和验证声音质量。

## 可迁移的正确理解

“获奖入围”是一组目标和比较标尺，不是提示词承诺。官方奖项的类别和评审偏重点不同：ADC把Motion Graphics定义为将字体、插画、Logo、形状与视频组合起来讲故事，并把动画、导演、剪辑、声音、字体等作为独立工艺类别；D&AD动画类别强调craft；World Illustration Awards公开标准包括技术执行、信息传达与媒介探索。真正入围还取决于参赛类别、当届对手和真人评委。

因此本项目把视频的1–10口号改造成可审计的百分制、硬门槛和盲审协议，详见`docs/mg-award-quality-gate-v001.md`。

## 推荐制作流程

`创意简报 → 参赛类别与参考集 → 概念/脚本 → 风格帧三方向 → 动态语法测试 → 最难10秒Demo → 独立盲审 → 修订 → 全片Animatic → 全片粗剪 → 声音与精修 → 技术QC → 外部真人评审`

### 输入控制

- `brief.md`：受众、信息目标、片长、画幅、用途、品牌限制和唯一一句主张。
- `category.md`：拟对照的奖项类别与该类别重视的工艺；只作为基准，不宣称会入围。
- `reference-set.csv`：8–15个获奖/入围或高端商业参考，逐条记录来源、年份、可借鉴属性和禁止复制项。
- `script.md / timeline.json`：每段信息、时长、视觉事件、转场因果和声音事件。
- `design-system.json`：字体、网格、色彩、形状、材质、镜头空间、动效曲线与随机种子。
- `rights-register.csv`：音乐、字体、图像、视频、模型和插件来源/许可。

只写“做得好看、国际MG、获奖级”不会产生可执行设计。提示中必须同时定义传播目标、独特机制、允许/禁止的视觉语言、声音角色和验收方式。

### Demo多轮迭代

| 轮次 | 产物 | 主要回答 | 放行标准 |
|---|---|---|---|
| D0 概念板 | 3条概念＋一句话机制 | 想法是否值得做 | 信息清楚、机制不同、无抄袭依赖 |
| D1 风格帧 | 每方向3–5帧 | 设计系统是否成立 | 构图、字体、颜色、资产语言通过 |
| D2 动态语法 | 每方向3–5秒 | 运动是否属于这套设计 | 缓动、层级、镜头、转场可重复定义 |
| D3 最难镜头 | 8–12秒，含声音 | 核心创意和最高风险能否实现 | 独立评审总分≥85，无单项<75，无硬失败 |
| D4 Animatic | 全片低保真＋临时声轨 | 叙事、时长与高潮是否成立 | 无冗段，信息可懂，节奏曲线明确 |
| D5 粗成片 | 全片80%质量 | 系统是否能撑完整片 | 一致性、变化密度、声音结构通过 |
| D6 精修母版 | 最终画面、混音、字幕、交付包 | 是否达到提交标准 | 双人技术QC＋独立盲审＋权利清单通过 |

每轮保留全部候选、准确提交原文、模型/工具版本、依赖、输出哈希、评审JSON和修改单。评审subagent不能直接改成片；它只提供带时间码证据的诊断，由制作Agent根据修改单返工，防止评审与制作共享同一盲点。

## 视频方法的风险

- 同一个模型派生出的subagent并不等于独立人类评委；其分数可能自洽但校准错误。
- “不使用Skill”适合测试基础能力，不适合作为生产原则；生产应复用经验证的设计系统、渲染和QC能力。
- 22个短Demo覆盖面很广，但容易优化成风格贴纸集；获奖作品更看重概念、传播和整片控制。
- 用同一评审提示反复优化可能产生对量表过拟合，需保留隐藏审查项和外部真人复核。
- 1,915个镜头/素材单元与66个入选项是视频作者展示数据，未获得工程文件，无法验证计数口径。
- P5R案例从18支官方宣传片取材；“官方发布”不等于允许再剪辑或商业传播，研究分析、Demo和公开成片必须分开管理并核验许可。
- 平均分会掩盖致命短板，必须设置单项底线和版权/文字/技术硬失败。

本次另由独立subagent在不修改项目文件的条件下审评流程。它确认核心价值是“最高可操作标准＋独立盲评＋门槛制迭代＋版本证据链”，并指出同模型评审偏差、Goodhart式刷分、素材权利、自写WebGL/Python音频的确定性与交付风险。完整意见见`independent-review.md`。

## 适用场景

适合MG品牌片、片头、解释动画、音乐视觉、风格探索和Agent能力基准。若目标是真实奖项投稿，应先选定具体奖项、年份和类别，再按官方资格、字幕、权利和提交规格准备；本案例不构成入围预测，也没有授权付费生成或实际投稿。
