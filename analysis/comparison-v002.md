## 各案例技术链条

### 001：先把风格变成约束

约00:12–00:30：参考视频 → 上传/分析界面 → 从色彩、人物与环境比例、构图秩序、空间层次、环境动态五维提取规则。

约00:31–01:13：规则具体化 → 大面积色块与对比、小人物/大环境、对称/阵列/留白、层次、环境运动 → 组合为新的画面要求。

约01:14–01:22：换主体和场景的示例 → 用视觉规则检查风格能否迁移。

中间产物应区分“分析表”和“生成要求”。画面可证明作者展示过规则表及示例，不能证明示例实际采用了屏幕中全部规则。模型、完整提交原文、输入对应关系、参数及候选未知。核心价值是将风格名称转成可检验的视觉条件；尚不覆盖完整剧本、声音和剪辑流程。

此案例展示了较多操作与中间产物，但未能从采样证据建立每个生成输入到最终输出的完整对应。不能直接据此宣称端到端全自动电影制作。字幕中提及的具体工具名、节点模型、版本、准确提示词、失败重试成本和最后剪辑交付方式仍需逐项核对。

### 003：代码编排的产品视频

约00:00–00:09：产品素材/目标 → “video-shotcraft” Skill → 视觉定调、分镜设计、页面呈现。

约00:09–00:15：录制、动画、声音设计 → 宣称最后由Remotion渲染导出。

约00:15–00:29：展示镜头、动效、分类音效库与卡牌转场/3D模板，主打SaaS/App/桌面软件发布视频。

这里的主要控制是代码、模板、时间线和资产库。不能由“电影感”字样推断其生成真人电影镜头。库容量数字只是视频宣传文字，本轮未核验。Skill源码、安装路径、真实输入、脚本、渲染参数与音频来源未知。适用于可编排的产品演示这一定位来自视频内容，不是对当前工具的外部推荐。

### 004：把静态要求写成作用关系

约00:06–00:16：用“文字从主体中间穿过去”说明文字与主体的空间交互。

约00:16–00:24：用“主体撑破/顶出画面”等表达突出主体；约00:24–00:32用产品与相异材质的碰撞营造反差。

约00:33–00:42：让元素争夺、竞争或互动，形成视觉张力。末段强调用动作词表达设计意图。

链条：产品/主体 → 空间作用、材质冲突、元素关系的文字描述 → 产品视觉示例。没有可见的完整生成提交过程，属于提示词表达法，尚不能当作视频运动控制方法。“动作词”可能描述静态画面的关系，也可能描述时间动作，实验时必须分开。完整提示词、模型、输入、参数和失败候选未知。

| 约略时间 | 操作/主张 | 中间产物与用途 |
|---|---|---|

白模应保留足够场景结构，并用颜色或编号区分角色。生成说明要规定哪些几何关系、轨迹与镜头必须保留，哪些外观可以改变。屏幕Prompt含模糊区域，本轮不转录成“准确提交原文”。工具名、GPT标签和比例数字均作为作者陈述记录，不据此推定当前产品事实。

## 共同流程与适用边界

共同骨架可写为：目标/故事 → 参考与规则 → 资产 → 分镜/预演 → 镜头制作 → 声音 → 剪辑交付 → 复核与记录。但五片并未共同证明这一完整链条；P0剧本质量、P6最终剪辑、跨镜头连续性和成本统计仍有明显证据缺口。

可组合的研究路线：用001的方法提炼视觉规则；借002组织人物和场景资产；需要明确空间/动作时引入005预演；004的关系词作为表达补充。003的代码路线更适合视频中所展示的产品演示任务，可独立成支线。此处为研究者归纳，未提交生成或安装视频里宣传的技能。

## 待验证事项

- 准确指令：逐个核对生成提交画面的完整原文；模糊/截断内容保留未知。
- 输入对应：保存实际素材哈希、身份映射、上传顺序与参考权重；教程视频本身的哈希不能替代生成输入哈希。
- 稳定性：保留失败候选，检查多次生成、跨镜头身份和空间连续性。
- 运动与声音：连续审查轨迹、动作因果、遮挡、对白、音乐和音效，不能从联系表判定通过。
- 成本与自动化：用实际调用/渲染日志核对，不采用宣传数字作为预算。

证据文件在analysis/001–005/v001内；002–005技术日志为decode.log，采样帧在frames，联系表为contact_*，002分钟章节索引为minutes_*。001的早期报告保留，新范围以本报告为准。

# 案例006：二维路线图控制人物走位

来源：stodownload (8).mp4，34.92秒，720×1280，30fps。SHA256见references/006/provenance.json。每3秒采样及11–25秒原分辨率补充帧已静态检查；连续运动和声音未审查。

流程：场景图 → 手绘人物行进路线 → 用1–5标注分镜位置/顺序 → 加入角色参考图 → 在每段镜头提示词中对应位置与动作 → 生成候选 → 对照路线。

约11–18秒展示俯视场景、红色路径及编号；约18–21秒展示标注场景与人物参考、输出；约21–24秒展示分镜提示词，包含镜头时段、景别、角度、camera_move、subject_action、lighting_shift、transition等字段，文本部分截断，不能作为完整准确原文。约24秒至结束并置Seedance 2、mini、fast标签的示例，具体服务版本和实际提交记录未知。

分类：P3分镜/P4生成；C1文字、C2参考、C3分镜。进一步新增C7二维空间/路径标注，与C4三维预演分开。

关键交接：编号须与提示词镜头段落一致；人物参考须明确身份；路线图说明的是空间路径，不自动保证动作时长、相机轨迹、遮挡及跨镜头连续性。视频的“无需抽卡、精准控制”是作者主张，重复结果、失败候选、输入哈希、上传顺序、完整原文及参数未知。证据E2/E3；复现R1，未独立实验。
