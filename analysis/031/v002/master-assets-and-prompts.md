# 案例031：三类母版与提示词控制专项

## 证据与结论

研究对象：[《长安异闻录 第三卷｜惊夜》工作台](https://www.liblib.tv/creation/process?id=386cfd274d084d2ba9add9dc8480427e)。证据细读见[原始内容记录](original-content-details.md)。本文件分析保存于界面的框架与镜头文本，不声称获得作者完整历史提交。

| 对象 | 已直接读到 | 尚未知 |
|---|---|---|
| 场景 | 陈家银饰铺框架：时代、身份、布局、材料、摄影、光线、排除项 | 每张场景图实际提交原文、生成参数、多视角一致性 |
| 人物 | 刘信七框架：脸、毛发、体型、服饰、四视图、棚光与限制 | 身份是否经过跨镜头验证，角色板实际生成记录 |
| 道具 | 道具资产名称；查镯镜头明确引用图片3，约束造型、厚度、旧银材质与纹样 | 银镯独立生成提示词、尺寸、纹样图、源文件与哈希 |
| 镜头提示词 | 8秒查镯、24秒界面公堂节点完整文本及保存设置 | 历史真实运行参数、完整候选对照、费用与有效率 |

本轮尝试通过节点搜索补查银镯原文，未成功进入其详情，因此不补写作者的道具提示词。以下所有“本地建议”和模板均为我们的归纳。

核心可采用点：先把可复用世界、角色和物件定义稳定，再为每个镜头分配参考职责、初末状态和可检查事件。母版不应只是精选美图，应包含图片、说明、版本、适用范围与审查状态。制作记录规范可立即采用；生成效果仍为S1研究结论。

## 场景母版：锁住可拍摄的空间

### 原案例怎样组织

陈家银饰铺先定义盛唐开元、洛阳支巷、中等规模稳定经营的银饰铺，再写入口、柜台、右窗、后部储物和门帘。这个顺序将生活身份落实为建筑规模与陈设，能减少豪华珠宝店式误读。

柜台把顾客区与银匠区分开，门帘提示后屋，右窗提供查验银镯的动机光。材料和工具说明职业功能；无人大全景为后续人物走位留出空间。这里的优势是场景本身能够支持剧情动作，而不是只有气氛。

### 需要补齐的控制

| 层 | 固定内容 | 可变内容 | 检查方式 |
|---|---|---|---|
| 世界 | 时代、城市、场所身份、规模 | 剧情日期、天气 | 世界设定表；标题与地点差异待核 |
| 建筑 | 门窗、柜台、梁柱、后屋关系 | 柜门开闭、门帘状态 | 平面简图与多机位对照 |
| 使用 | 顾客区、工作区、通路、动作空间 | 人物站位、可移动桌椅 | 走位预演，检查碰撞与遮挡 |
| 光源 | 窗位置、室内实际光源位置 | 时段、亮度、天气 | 同时段正反打光源对应 |
| 摄影 | 可用机位、轴线与地标 | 景别、焦段意图、运镜 | 机位图及相邻镜头接戏 |

“画面右侧窗”只对当前机位成立。我们应以固定建筑编号定义窗W01、入口D01、柜台C01，再说明该镜头里它们位于何处；反打不能把建筑翻转。焦段词表达构图意图，不证明生成模型使用真实摄影机参数。

### 本地交付包

最小包：无人主视图、布局简图、门窗与通路说明、光源说明、版本与审查。按镜头需求再补反打/侧向/局部图。不同方向的图必须共同核对，不能各自生成得漂亮就批准。

场景状态用同一母版派生：`SCN-SILVER-01 / DUSK / v001`。昼夜变体保持拓扑；物件搬移则记录位置变化。场景美术通过后，仍需验证人物能坐、能进出、手能触到台面。

## 人物母版：身份与剧情状态分离

### 原案例怎样组织

刘信七的锚点是约45岁商人、长脸、眉骨、细眼纹、薄唇、细髭短须、少量灰发、发髻和肩背轮廓。紫褐外袍、深蓝内衫与布靴提供整体辨识。浅灰棚底减少环境干扰；脸近景和全身分别服务表演与走位。

四视角板兼顾身份、体型与衣着，是沟通总览的有效方式。但四格共用一张图会压缩脸部像素，也可能被模型理解为多人。不能从文字要求“四格同一人”推导输出已经一致。

### 本地拆分

| 层 | 例子 | 变更规则 |
|---|---|---|
| 身份 | 骨相、脸型、年龄范围、身体比例、稳定辨识点 | 换脸或改变年龄须作为新版本审批 |
| 造型 | 发型、胡须整理、衣服、鞋、配饰 | 绑定服装/造型ID，保留旧版 |
| 剧情状态 | 清洁、受伤、疲惫、湿衣、囚服 | 随场次变更，记录发生时间与继承关系 |
| 表演 | 此刻注意对象、意图、情绪、动作 | 镜头任务规定，不写死在身份母版 |

例如商人服与囚服应引用同一人物身份，不能各自重新随机设计一张脸。受伤位置、污渍和衣物破口要进入状态表；某次镜头的恐惧表情不应成为人物永久默认表情。

最小交付：总览板、独立正脸、三分之四脸、正面全身与必要背面；各图关联同一身份版本。独立视角应先检查身份，再决定用于哪些镜头。裁片记录父图和裁切范围；裁切不能凭空增加细节。

### 质量门禁

同组图片核对骨相、五官比例、年龄、毛发、体型与服装细节；跨景别检查观众是否仍能识别同一人。再做转头、手持道具和表情变化的短测试。静态通过与运动通过分别记录，不以“脸像”掩盖身体或衣服漂移。

## 道具母版：物件身份与交互状态

### 原案例可确认的做法

银镯在查验镜头中具有独立参考职责：形状、厚度、旧银材质与纹样。角色负责“谁在看”，场景负责“在哪里及借什么光”，道具负责“看的是否仍为同一个东西”。这体现了关键物件从环境装饰中独立出来的价值。

不能据此确认作者已经建立尺寸表、全套视图或纹样定位。道具资产列表还包括钱袋、钥匙、工具箱、烛台、屠刀等，名称存在不代表这些资产全部完成统一标准。

### 本地建议分级

| 级别 | 用途 | 必需控制 |
|---|---|---|
| 背景陈设 | 不承担线索和动作 | 类别、时代、材质、摆放范围 |
| 交互道具 | 持握、放下、打开、使用 | 相对尺度、结构、接触点、运动限制 |
| 叙事关键道具 | 证物、身份线索、产品主体 | 独特纹样/缺损、状态与保管流转、跨镜头身份 |

银镯至少按交互道具管理；若其纹样承担破案线索，升级为叙事关键道具。这一升级取决于剧本，不能仅凭名字判断。

建议补充：正面/侧面/三分之四视图、关键纹样细节、与手掌的相对尺度、金属粗糙度与旧痕、开口/闭环结构。绝对尺寸未知时写未知，先明确可握范围；不能擅自填写厘米数。

对查镯动作建立状态链：`台面位置A → 指定手拿起 → 借窗光转动 → 同一手放回位置B → 脱手停稳`。手别、纹样朝向、接触与脱离、遮挡后再出现均需核验。具体A/B和手别在正式镜头设计时确定，不能冒充原案例原值。

## 提示词：将母版组合成一次镜头任务

### 原案例的有效结构

查镯节点将三张图分别绑定场景、人物、道具，再安排四个时段的摄影、表演、声音和结束动作。公堂节点进一步写出门槛两侧、押解路径、儿子转向和对白次数。两者最有价值的共同点是：把“自然、连贯、电影感”等目标落实为具体事件。

| 层次 | 要回答的问题 | 原案例对应 |
|---|---|---|
| 输出目标 | 生成什么规格与叙事功能 | 查验银镯；8秒、16:9、1080P界面 |
| 参考职责 | 每份输入提供什么，哪些不能照搬 | 图1空间、图2身份、图3道具 |
| 初始状态 | 人、物、机位、光线从何开始 | 坐姿、柜台、窗光 |
| 动作节拍 | 哪些事件按何顺序发生 | 转向光→抬镯→转镯→落桌 |
| 摄影表演 | 从哪看，人物为什么做 | 面部偏角、微眯眼、克制动作 |
| 声音 | 谁说什么，环境与接触声何时发生 | 无对白；衣料、金属与木台接触 |
| 末态与验收 | 什么算完整，可接到哪里 | 坐姿不变、落镯后停顿 |
| 限制/返工 | 不能发生什么，只改哪些问题 | 禁站起、禁纯侧拍；公堂修方向 |

### 不能照单全收的部分

1. **提示词与参数冲突**：公堂原文23秒、界面24秒。正式提交应先解决冲突，分别存计划值、界面值、实测值。
2. **任务密度**：8秒内四段动作，公堂多图多角色七段，易出现遗漏。先判断每段能否看懂、是否留剪辑余量；必要时拆为独立镜头。
3. **方向歧义**：“正面偏左或偏右”不能锁轴。确定机位侧、视线目标、手别及物件位置。
4. **负面词重复**：重复“不站起”表达重点，不提供物理保证。正向描述姿态与可见支撑关系，配合匹配参考和运动审查。
5. **技能名字**：`/sd25-pe`、模式名和版本是文本中可见标签，不证明执行了相应代码或插件，不直接移植为本地依赖。
6. **选择性修复**：文本说“保留正确表演”不保证重生成不会改变它。保留成功原片，比较拆镜、局部编辑和后期选片的成本。

### 我们的编写顺序

先形成结构化镜头合同，再按具体模型支持的能力编写提交文本。合同保留资产ID和验收字段；提交文本使用平台实际可识别的图片/音频编号。不要假定模型能够读取本地资产ID或自动打开文件。

优先级建议：身份与叙事事实 → 空间/交互正确 → 动作可读 → 摄影美术 → 装饰性修辞。先消除矛盾，再删去与镜头无关的母版细节；并非越长越好。平台是否支持专门负面词字段须核对，不强行拆字段。

## 本地验证与入库闭环

新增[母版与镜头提示词合同模板](../../../framework/templates/master-asset-contract-v001.md)。本轮仅形成文档，不生成图片或视频。

验证建议以一个场景、一个角色、一个交互道具和三个相邻镜头起步：建立镜头、查验动作、放回特写。基线使用原有自由描述，改进组使用资产职责和初末状态。尽量保持同模型、参考文件、时长与候选预算；不支持种子控制时注明，不能声称严格随机对照。

记录身份错误、空间错误、道具变化、手物接触、动作完成、可剪余量、返工次数、人工时间和费用；样本很小时只报告观察，不宣称统计优势。若身份稳定但动作变差，分别诊断，不以单个总分掩盖退步。

通过记录模板检查只代表交接完整；真实生成和连续审查后才能升级成熟度。场景反打失败回到空间母版，人物漂移回到身份/参考选择，道具穿模回到交互与镜头设计，避免所有问题都靠追加形容词处理。
