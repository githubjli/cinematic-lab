# 案例006：二维路线图控制人物走位

来源：stodownload (8).mp4，34.92秒，720×1280，30fps。SHA256见references/006/provenance.json。每3秒采样及11–25秒原分辨率补充帧已静态检查；连续运动和声音未审查。

流程：场景图 → 手绘人物行进路线 → 用1–5标注分镜位置/顺序 → 加入角色参考图 → 在每段镜头提示词中对应位置与动作 → 生成候选 → 对照路线。

约11–18秒展示俯视场景、红色路径及编号；约18–21秒展示标注场景与人物参考、输出；约21–24秒展示分镜提示词，包含镜头时段、景别、角度、camera_move、subject_action、lighting_shift、transition等字段，文本部分截断，不能作为完整准确原文。约24秒至结束并置Seedance 2、mini、fast标签的示例，具体服务版本和实际提交记录未知。

分类：P3分镜/P4生成；C1文字、C2参考、C3分镜。进一步新增C7二维空间/路径标注，与C4三维预演分开。

关键交接：编号须与提示词镜头段落一致；人物参考须明确身份；路线图说明的是空间路径，不自动保证动作时长、相机轨迹、遮挡及跨镜头连续性。视频的“无需抽卡、精准控制”是作者主张，重复结果、失败候选、输入哈希、上传顺序、完整原文及参数未知。证据E2/E3；复现R1，未独立实验。
