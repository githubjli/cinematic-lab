## 视频讲述的技巧

视频先展示同类知识短片数据和项目仓库，再演示把Skill安装给Agent，要求它用故事寓言方式解释《反脆弱》中的杠铃策略。Agent先形成`brief.md`、`facts.md`、`storyboard.md`，再编码生成“粮仓与小船”的约2分48秒样片/成片，最后放进剪辑软件检查并另配BGM。

项目官方定义两种风格：

| 模式 | 适合内容 | 表达方式 | 声音 |
|---|---|---|---|
| C 夜曲 | 抽象概念、看不见的机制、知识实验 | 深色、发光、结构演示；无旁白，字幕主叙事 | 代码登记事件音，程序合成声床/变化音 |
| B 寓言 | 心理、行为、策略，从动物或生活故事切入 | 角色与场景演出因果 | 用户提供BGM，再叠事件音；仓库不替用户取得音乐权利 |

最有价值的技巧是“配图不是讲解”：画面主体必须能用日常名词叫出来，字幕里的动词要在画面真实发生。抽象点线如果换到任何文案仍成立，只是装饰，不是解释。

## 官方流程拆解

`题目/文案 → 事实表 → 给概念找生活形象 → 文案与分镜同步写 → 选择B/C世界 → 先做最难一镜 → 前30秒样片 → 铺全片 → 事件音/BGM → 三遍终检`

1. **立题与事实表**：写一句话论点、3–12个概念、外行理解障碍、年份/人名/数字的出处与置信度。
2. **找形象**：判断概念是东西、过程、量、心理活动还是规律；寻找生活锚点、尺度变化、故障状态和全片会回场的道具。
3. **文案与分镜共写**：每句字幕同时写画法、主体、动作、小字、观众应理解的内容和声音；没有分镜表不建工程。
4. **选外观**：心理/行为故事选B寓言，抽象机制选C夜曲。外观在讲解设计之后确定。
5. **建立代码工程**：`new_film.py`只产生空骨架；具体画面仍需按本片分镜编写`film.js`。
6. **先做难镜和前30秒**：用静帧、拼图和动作序列检查；30秒只讲清一件事，不为了覆盖全文压缩理解时间。
7. **逐帧渲染**：Canvas/JavaScript把画面定义成时间`t`的函数，Playwright驱动Chrome跳转到各时刻截图，FFmpeg编码H.264；可分段并行与局部重渲染。
8. **声音**：`fr.sfx()`把事件写入JSON；`audio.py`用NumPy/SciPy程序合成tick、chord、rise、thud、shimmer等音效，再通过FFmpeg与视频/BGM混合。
9. **终检**：静音遮字幕看画面、只读字幕查逻辑、再按事实/结构/字幕/画面/节奏/技术门逐项检查。

## 输入与输出控制

### 输入

推荐固定为四份文件：

| 输入 | 只放什么 | 不允许混入什么 |
|---|---|---|
| `brief.md` | 受众、论点、时长、画幅、语气、交付目标 | 未核实事实和具体镜头实现 |
| `facts.md` | 事实、数字、原始来源、置信度、允许措辞 | 无来源的强结论 |
| `storyboard.md` | 每句字幕对应主体、动作、小字、声音与理解目标 | 泛化的“高级感”“震撼” |
| `design.md` | B/C选择、颜色语义、字体、字幕安全区、声音规则 | 改写故事事实 |

若用户只给选题，AI先输出事实表和三种钩子；若已有文案，保留原文和修改版的差异。所有模型提交原文、上下文文件哈希和用户采用版本都应保存。Skill中参考材料只能提供方法，不能成为事实来源。

### 中间输出

每个概念对应一个函数，每个镜头保存ID与时间范围。先输出指定时刻静帧、全局sheet和转场motion sheet，再输出30秒clip。`seek(t)`必须是纯函数，随机数固定种子；仓库提供`--det`把同一批时刻乱序重截并逐字节比较。

### 最终输出

官方目标为1920×1080、30fps、无旁白横屏；项目交付包含`storyboard.md`、`film.js`、事实表和`renders/final.mp4`。我们还应补充：依赖锁、源码快照提交、渲染命令、事件表、分轨音频、候选/返修历史、每个输出哈希与审查状态。

## 制作方式与依赖

本地源码显示依赖`playwright`、`numpy`、`scipy`、`Pillow`，另需本机Chrome与FFmpeg。其渲染器启动仅监听`127.0.0.1`的临时HTTP服务，按1920×1080视口截图；可生成静帧、拼图、动作拼图、局部clip、全片并行分段和事件JSON。音频脚本以48kHz生成立体声，再按有无外部BGM选择不同响度目标并用AAC封装。

这套方案适合几何、示意、程序绘图和无旁白知识短片。它不等于通用AI电影生成器，也不自动完成原创研究、事实核验、复杂人物动画或专业混音。作者当前Skill声明只做16:9；视频本身是720×960平台转载画幅，不能把转载画幅误认为工具输出规格。

## 值得收集的制作规则

- 先找形象，再写文案；画不出来的句子需改写或明确“不画”。
- 先例子后术语；开头让观众看见一件事发生，再出现片名。
- 一个世界、一把尺子、少量道具贯穿；每句只改变一处。
- 提问、命名、结论、引文不必强行配新画面。
- 遮住字幕做三问：这是什么、它在干什么、我明白了什么。
- 先做最难一镜，再做30秒样片；至少经过静帧和动作序列审查后才铺全片。
- 文件存在、确定性通过和视觉讲清楚是三个不同状态。
