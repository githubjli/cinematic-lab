## 核心结构

`品牌资料 → 时间轴与主张 → 戏剧化人物/道具 → 分镜表 → 关键帧/镜头候选 → 年代信息卡与转场 → 剪辑、声音和事实复核`

### 1. 先做品牌事实表

把创立年份、创始人、关键产品、技术突破、市场节点和可使用档案素材逐项记录来源。每条事实附允许措辞、置信度和证据链接，避免AI把品牌宣传语写成历史事实。

### 2. 从时间轴提炼一条视觉母题

本片选择“图纸”作为贯穿道具：看图、画图、尺规测量、图纸变成产品。它把“工程、精度、传承”从抽象词变成连续动作。品牌片应先确定这种可反复出现的物件或行为，再决定风格。

### 3. 用“戏剧镜头＋事实节点”交替

连续几个工作动作建立情绪和可信世界，随后插入年份、人物或产品信息；再回到动作场景。这样比从头到尾排列年份字幕更有观看性，也能让观众分清情绪镜头与事实信息。

### 4. 分镜表必须可执行

每镜至少写：镜号、时长、景别、机位、运动、主体、动作、起止构图、道具、光线、文字、转场、声音、事实来源和连续性锚点。视频表格已有景别、运镜、参考图和内容，但缺少时长、声音、生成约束、事实出处和验收标准，实际制作前应补齐。

### 5. 关键帧与视频分开控制

先生成或制作角色、服装、工作间、图纸、尺规和产品的设定图，再为每镜确定首帧/尾帧。人物身份、胡须、服装、桌面布局、道具尺寸和光源方向建立资产ID；视频生成只负责镜内动作，不能每镜重新发明人物和空间。

### 6. 信息卡单独制作

1921、1950等年份、姓名、成就和产品名称应在可编辑的字幕/动态图形层制作，不建议烘焙进生成画面。这样可以校对文字、替换语言、控制安全区，也能避免AI生成乱码。历史照片应保存来源、授权和裁切记录。

### 7. 转场服务于因果

第8镜的尺规与设计图承担“设计成为产品”的视觉桥梁，烟雾连接下一个年代。转场应提前写清入点、出点和共享形状；烟雾、叠化或匹配剪辑只负责跨时空，不应掩盖事实跳跃。

## 适合AI参与的环节

| 环节 | AI可以做什么 | 必须人工控制什么 |
|---|---|---|
| 资料整理 | 把经确认资料转换为年代卡和候选旁白 | 来源真实性、法律与品牌表述 |
| 脚本 | 从时间轴提出多条叙事线和视觉母题 | 核心主张、取舍、避免空泛赞美 |
| 分镜 | 补全景别、动作、机位和首尾状态候选 | 空间连续、镜头动机、节奏与可拍性 |
| 视觉开发 | 生成年代氛围、人物与场景候选 | 身份一致、产品准确、历史细节 |
| 镜头生成 | 生成短动作、材质特写、转场元素 | 手部/工具接触、几何结构、品牌标识 |
| 后期 | 辅助字幕、代理、镜头排序和版本比较 | 字体、文字正确、混音、品牌审片 |

## 最值得借鉴与需要避免的地方

- 借鉴“一个人物、一个场所、一个核心道具”建立品牌世界，降低跨镜头一致性难度。
- 借鉴特写—中景—信息卡的节奏变化，让手艺细节和历史跨度同时成立。
- 把品牌年份做成叙事节点，而不是背景装饰；每次出现都回答“发生了什么、为何重要”。
- 不要仅凭一张参考图让AI猜整镜；明确首尾构图、人物动作和摄影机运动。
- 不要让生成模型直接写品牌名称、年份和产品说明；采用可编辑文字层并逐字校对。
- 不要用“复古、电影感、高级”替代年代美术：服装、工具、灯具、材料、产品形制分别核验。

这类流程适合品牌周年片、创始人故事、工艺传承、产品演化和博物馆序厅短片。若品牌史资料稀少或法律审查严格，应把档案证据和授权放在画面生成之前。当前完成静态流程识别；没有执行生成、付费调用或独立复现。
