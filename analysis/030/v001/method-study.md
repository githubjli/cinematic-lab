## 它是什么

视频里的SKY-001是Skyfall AI于2026年10月19日发布的工程世界模型，不是AI影视工作台。官方将其定位为面向CAD与BIM的层级视觉规划模型：从文字、参考图或空间约束出发，把复杂对象分解成装配体和零件，再预测每个零件的构造状态、二维草图与三维操作序列。

截至本次核对，官方页面只提供介绍、演示和候补名单入口；未找到官方公开代码、权重、API文档或明确开源许可，因此不能作为当前可下载的开源项目收集，也不能在本地复现。

## 官方流程拆解

`设计目标/参考图/约束 → 多个目标设计候选 → Hierarchical Composer层级分解 → 叶子零件 → Construction World Model逐步构造 → 2D草图与3D状态序列 → 按层级装配 → CAD/BIM视觉设计方案`

### 1. 先决定目标，再展开细节

同一设计意图可以先产生多个目标候选，由用户选择一个，再向下分解。这个“先锁方向、再付出细化成本”的方式与影视的风格帧/Demo门禁相同。

### 2. Hierarchical Composer

复杂产品不被当作一个平面网格一次生成，而是拆为：

`整机 → 主装配体 → 子装配体 → 零件组 → 零件 → 子零件/特征`

父级为子级提供上下文。官方认为这样可让叶子零件并行生成，并把顺序长度从对象总零件数压缩到层级深度。

### 3. Construction World Model

对每个叶子零件，模型先规划三维实体逐步变化；相邻三维状态之间反推出对应二维草图和操作。二维部分先在压缩空间中粗略逐笔展开，再由refiner补细节。BIM任务从建筑轮廓分到单元和房间，并生成二维绘制状态。

### 4. 按父子关系重新装配

最终输出不是孤立零件图库，而是包含设计树、各叶子的构建序列及装配关系的视觉设计计划。视频展示汽车、摩托车、机器人、发动机和建筑层级，也展示爆炸图和零件数量对比。

## 视频和官方页面中的性能数据

官方声称在1,000个CAD部件基准上，SKY-001平均约3.9秒/例、0.005美元/例、最终三维IoU 79.7%；其页面给GPT-6 Astra的对照为199秒、0.75美元、79.1%。BIM基准官方声称约1.22秒/方案、0.0024美元、IoU 43.6%。

这些数据来自厂商自建基准和厂商页面。视频没有提供测试集下载、运行代码、统计置信区间或独立第三方复现；两名LLM盲评也不能代替机械可制造性、装配干涉、约束完整性和工程师签核。

## 对AI影视制作的借鉴

SKY-001本身不负责剧本、表演、镜头生成或剪辑，但它的方法可迁移到资产密集型影视生产。

### 层级资产树

把复杂镜头拆成：

`世界 → 场景 → 区域 → 建筑/载具 → 装配体 → 零件 → 材质/约束`

先锁父级空间、尺度、风格和接口，再并行制作叶子资产。这比让模型一次生成“完整未来城市/机器内部”更容易保持一致。

### 构造序列就是动画蓝图

零件的有序构造状态可直接转化为产品片和科普片的动画：草图出现、拉伸、切割、装配、爆炸、复位。每一步都有前后状态，适合确定性插值、局部重渲染和声音事件绑定。

### 父级上下文约束每个镜头

每个零件镜头都携带所属装配体、坐标、比例、接口和材质，而不是只看局部参考图。对应到电影，是角色/道具/场景资产ID和空间关系随镜头传递。

### 候选先行与分层审评

先比较整体形态候选，再展开高成本细节；审查也分为总体轮廓、装配关系、零件几何、构造步骤和最终视觉。不能用最终漂亮渲染掩盖内部结构错误。

## 可用于哪些内容

- 工业产品发布片、机械爆炸动画和装配演示；
- 工程、建筑、航空航天和机器人科普；
- 复杂机械世界观的概念设计与资产规划；
- 以“从草图到产品”为叙事的品牌历史片；
- CAD/BIM数据进入Blender或代码动画之前的结构规划。

## 不能直接推断的能力

- 视觉相似或IoU较高不证明工程可制造、受力安全或满足行业标准。
- 从单张图推断隐藏结构必然含假设，不应当作真实产品逆向工程结果。
- 官方将未来方向扩展到PCB、航空、能源、蛋白质和机器人；这些是路线图，不是视频已经验证的成熟能力。
- 当前无公开下载，不能列为本地优先工具，也没有付费调用授权。

## 建议纳入本项目的方法

新增“层级世界分解＋构造状态序列”控制模式：

```text
asset-tree.json
  parent_id / child_ids / local_transform / interface_constraints

construction-sequence.json
  state_id / previous_state / operation / geometry_ref / camera / sound_event
```

对机械或建筑题材，先做资产树和最难装配Demo；分别审查轮廓、拓扑、接触关系、连续运动和声音。即使将来取得SKY-001访问，也只把输出作为候选设计计划，必须经CAD工具、物理检查和工程师复核。
