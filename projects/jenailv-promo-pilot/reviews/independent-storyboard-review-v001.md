# 金耐力9:16连续故事分镜独立评审 v001

评审日期：2026-10-22  
评审对象：`continuous-storyboard-v001.jpg`、`continuous-storyboard-v001.md`、`continuous-storyboard-v001.csv`。  
评审限制：本次仅审查静态故事分镜与文字合同，未审查连续动画、声音或真实机械结构。

## 总结论

**不通过进入视频样镜。**

文字规划的叙事链条成立，连续性合同也抓住了正确问题：同一批物料、统一运动方向、压板持续接触、门先开启、推出机构后接触，以及用声音和形状连接镜头。这部分可作为下一版基础。

但当前视觉分镜没有兑现这份合同。S03和S04在压缩发生前已经出现完整成品包；S05同时展示松散物料和成品包；S06换成无纹理棕色灰模方块；S07又换成几乎纯白的真实料包。观众无法确认它们是同一批物料，也无法仅靠画面建立“松散废料被这台机器连续压缩并推出”的因果链。S07与S08在功能上还有结果重复和回跳，整组图更接近不同来源的设备画面陈列，而不是一个连续事件。

## 1. 故事连续性

### 文字版本：有条件通过

- “混乱 → 输送 → 入腔 → 压缩 → 开门 → 推出 → 仓储 → 品牌收束”的宏观结构清楚。
- S01以蓝色碎片为物体锚点、S02以输送带斜线连接S03、S04用落料声触发S05剖切，均属于可执行的匹配设计。
- S05和S06把关键机械顺序写成硬合同，方向正确。

### 视觉版本：不通过

- S03“机器苏醒”已经把巨大成品包放在机器出口，提前泄露并混淆后续压缩结果。
- S04标题是“落料入腔”，画面却仍是外部整机和成品包，未看到跟随同一批物料越过料斗并进入压缩腔。
- S05画面同时出现敞开的压缩区、松散物和外部完整料包，时间关系不明确。它像一张工程展示图，并不证明同一批物料正在经历两个连续密度状态。
- S06突然进入Blender灰模，设备、材质、相机和场景全部变化。虽然动作合同可能正确，但故事视觉连续性被中断。
- S07切到低清实拍和白色料包，既没有保持S06向右移动的速度/形状匹配，也没有证明它是S01开始的同一批纸塑混合物。
- S08再次使用与S03几乎相同的英雄图，视觉上像回到故事中段，而不是获得新的终局信息。

## 2. PPT感判断

**单张画面基本摆脱PPT感，整套分镜仍有“图库式PPT”感。**

单张生成图具备空间、景深和电影光线，没有浮动参数卡和信息面板。但八格之间混用生成图、工程灰模和官网实拍，摄影质感、清晰度、色温、设备结构与料包材质均不统一；S03和S08还直接复用同类英雄画面。这会让成片像按章节播放不同素材来源，而不是镜头带观众穿过一个连续空间。

真正消除PPT感需要依靠连续运动和画面内部因果，而不是仅把每张幻灯片换成电影感图片。下一版分镜必须先证明物体跨镜连续、运动方向连续和场景位置连续。

## 3. 物料身份与空间方向

### 物料身份：不通过

| 段落 | 当前身份表现 | 判断 |
|---|---|---|
| S01–S02 | 牛皮纸、透明/白塑料、少量蓝红碎片相近；蓝色碎片可以成为有效锚点 | 基本成立 |
| S03–S04 | 画面出现已经捆扎、密实的大料包，与前两镜的跟随物关系不明 | 中断 |
| S05 | 松散混合物和外部白色成品包同时存在，无法判断是否同一批 | 中断 |
| S06 | 棕色无纹理方块，无纸纤维、透明塑料、蓝红碎片或绑带延续 | 中断 |
| S07 | 几乎纯白实拍料包，与开场混合纸塑的色彩和表面完全不同 | 中断 |
| S08 | 前景料包与S03近似，再次改变结果身份 | 中断 |

下一版应建立一张“物料身份卡”：牛皮纸占比、白色塑料占比、蓝色碎片位置、红色碎片位置、绑带数量与方向、压缩后表面纹理。每个阶段都必须能看到至少两个稳定特征，而不只是都呈矩形。

### 空间方向：文字通过，视觉未证明

CSV规定左/上进入、右/下输出，但现有静帧没有可靠展示同一条轴线：S02的输送带指向画面纵深上方；S04未进入腔体；S05的剖切面和出口方向不够明确；S06灰模向右出包；S07实拍设备与料包的方向关系不同。当前只能在文字中读到方向，无法从镜头连续性确认。

下一版应先画一张设备俯视轴线图，标明入口、压缩方向、门、出口和相机位置。镜头换轴必须给出越轴过程或明确的匹配转场，不能用不同素材默认观众会自动理解。

## 4. S05/S06机械因果

### S05：文字正确，画面不成立

文字要求“压板持续接触 → 两个中间密度状态 → 匹配回真实外观”，这正是解决状态跳变的关键。但当前S05只有一个静态敞开结构，压板与物料的接触面不明确，也没有展示两个密度状态。外部已经存在的成品包反而暗示成包在压缩动作前完成。

进入样镜前，S05至少需要四张连续动作帧：

1. 散料充满同一腔体，压板刚接触；
2. 压板持续推进，散料第一次收缩，蓝红碎片仍可追踪；
3. 压板继续推进，材料密度提高、体积进一步缩短；
4. 压板停止，形成尚未推出的密实料包。

压板位置、接触面和物料前后边界必须在四帧中可比较，不能用发光、闪白或切镜隐藏替换。

### S06：动作原则正确，输入状态和驱动力仍不够清楚

文字和灰模均表达“门完全升起后再推包”，优于上一版的宏观动作。但当前分镜只有动作末态：看不到门从闭合到完全开启，也不容易辨认推出板何时接触料包。灰色圆柱/黄色板的具体功能对普通观众不自明。

S06进入样镜前至少需要三个明确状态：门关闭且料包静止；门完全打开、料包仍静止；推出板接触后料包才向右移动。若真实设备并非该结构，应先由工程师确认，不得用灰模假设替代产品事实。

## 5. S07/S08重复与跳跃

**当前存在功能重复和视觉跳跃，需要重构。**

S07承担“产品结果 + 空间收益 + 仓储秩序”，S08又以成品包前景和设备英雄画面重复“机器与结果”。S08没有给出新的信息，只把叙事从仓储结果拉回已在S03见过的机器视角，造成时间和空间回跳。

推荐二选一：

- **方案一，保留S07结果、让S08成为品牌收束。** S07完成单包进入仓储、与已有料包形成纵深；S08继续在同一仓储轴线上，以设备远景或厂房全线作为背景，确定性合成Logo和CTA。不要回到S03同机位。
- **方案二，压缩S07并重做S08为新的终局英雄镜头。** S07只用3–4秒完成“单包 → 多包”的匹配；S08展示设备、空出的作业空间和整齐料包在同一宽景中的完整结果，形成此前未出现的最终全景。

考虑55秒节奏，建议采用方案二：S07缩短，释放时间给S05/S06机械因果。当前S07长达9秒，但关键的压缩和开门推包各只有8秒，时间分配偏向结果陈列。

## 6. 进入视频样镜前必须修正

以下项目全部完成后，才建议制作第一支连续视频样镜：

1. **清除S03、S04中的提前成品包。** 这两镜只展示设备启动与同一批松散物进入，不得出现已完成结果，除非明确是背景中的历史库存且不会与主物料混淆。
2. **为S04补出真正的入腔镜头。** 同一片蓝色碎片必须从输送带末端越过料斗并进入固定空间位置，成为S05的开场锚点。
3. **把S05扩成至少四个动作状态。** 明确压板接触、两级密度变化和压缩终态；维持物料纹理与彩色碎片位置可追踪。
4. **把S06扩成至少三个动作状态。** 门先完全打开，推出板再接触，料包最后移动；标注真实驱动件和运动轴线。
5. **建立物料身份卡并贯穿S01–S08。** 统一色彩配比、表面纹理、绑带状态和辨识碎片；S06灰模与S07实拍不得再使用无关棕块或纯白包代替。
6. **绘制俯视空间轴线图。** 锁定进料、压缩、出口方向和各镜头相机位置，检查每次切换是否越轴。
7. **统一媒介和色彩。** 灰模、生成图与低清实拍只可作为制作参考，正式样镜需要统一设备比例、镜头焦段、色温、对比度和材质层级。
8. **重构S07/S08。** S07缩至3–5秒并完成单包到多包的结果；S08提供新的全局终态与品牌收束，禁止复用S03式英雄画面。
9. **重新分配时长。** 将S07释放的4–6秒优先补给S05/S06，让因果动作有足够屏幕时间，品牌尾帧保持简洁。
10. **先做S04→S06的12–16秒连续样镜。** 该段通过同一物料、同一空间、接触顺序、无瞬移和完整连续播放审查后，再扩展到55秒全片。

## 7. 通过范围

- **通过：** 一句话故事、八节点宏观顺序、连续性合同的原则、A/B/C总体风格配比。
- **有条件通过：** S01→S02的物料锚点、S05/S06的文字动作合同、55秒总体框架。
- **不通过：** 当前视觉分镜的物料身份、空间轴线证明、S03–S07连续性、S05/S06机械因果画面、S07/S08功能分工，以及直接进入视频样镜。

建议下一步只重做S03–S08关键帧和S04→S06连续动作板，不要先生成整条55秒视频。
