# 金耐力主体粗剪 v001 独立评审

评审日期：2026-10-22  
评审依据：`outputs/body-video-v001/contact-sheet-v001.jpg`、`outputs/body-video-v001/render-report-v001.json`、`planning/continuous-storyboard-v001.md`。  
评审限制：**本轮未连续观看55秒视频**。节奏、转场顺滑度、字幕实际停留时间、声音主观质感和音画同步仅能根据静态联系表、EDL与技术报告作条件性判断，不能视为连续看片验收。

## 判定

**REJECT / 当前版本不通过对外交付。**

它可以继续作为v002的剪辑结构底稿，但不能作为成片候选。宏观故事仍能辨认：松散物料 → 输送 → 设备 → 压缩/开门/推出 → 规整料包 → 现场证明 → 品牌收束。不过，大部分段落由单张静帧、固定字幕和轻运动承担，17–33秒突然切入16秒Blender机械预演，40–45秒又切成四张官网图片快切。媒体质感、运动密度和可信层级变化过大，整体仍有明显的“电影感幻灯片 + 中段机制演示 + 官网图集”结构。

## 1. 是否仍像PPT

**是，PPT感仍然明显。**

- 0–17秒由三张静态生成图分别持续5、6、6秒，依靠标题推进内容。单帧画面有电影光线，但连续表达仍是“一页一观点”。
- 33–40秒再次用一张静态结果图持续7秒，动作密度骤降。
- 45–55秒由生成图、官网厂房图和最终英雄图依次收束，功能接近“现场页—品牌页—结束页”。
- 统一的左下角标签与大标题有识别作用，但每段都采用同一信息结构，会强化模板页切换感。
- 真正连续的物体运动只集中在17–33秒机械段。前后镜头没有充分利用同一物料、同一运动方向或遮挡动作完成视觉接力。

联系表证明单张画面已经摆脱传统参数PPT，但剪辑语法尚未摆脱PPT。

## 2. 55秒叙事与节奏

### 叙事：有基础，因果链被媒介切换打断

- S01–S03建立“松散、有体积、进入流程、设备成为核心”，意图清楚。
- S04–S06完整占用16秒，能够成为全片唯一的过程证明。
- S07把结果重新落到规整料包，逻辑上承接机械段。
- 40–45秒官网快切和45–51秒“现场到交付”没有新增明确因果，更多是在追加真实性与品牌证明。
- 51–55秒“把体积，变成效率”是有效收束，但“效率”尚无已确认数据支持，只宜作为抽象品牌主张，不能与产能、节省比例等事实暗示绑定。

### 节奏：结构不均衡

- 前17秒三张静帧总时长偏长，开场缺少足够动作钩子。
- 机械段连续16秒，视觉语言和运动密度与前段差异过大，像插入一支独立说明片。
- 33–40秒单张结果图持续7秒，紧接机械高潮后容易泄速。
- 40–45秒四张官网图片每张1.25秒，突然从7秒静态进入快切，节奏变化缺少桥接。
- 45–55秒再次减速，形成“慢—长演示—慢—快—慢”的拼接感，而不是逐步加速、达到峰值、最后收束的单一弧线。

## 3. 17–33秒Blender段与写实段衔接

**机械信息可读，但风格衔接不通过。**

- 前段是高质感写实生成图，进入机械段后立即变为简化几何、演示台式厂房和规则彩色块，写实度、镜头语言、材质复杂度和空间尺度同时下降。
- 机械段使用蓝色机架、黄色压板、棕色料包，色彩上与前后画面相关，这是当前唯一的衔接优势。
- Blender料包上的规整红蓝白方块和黑线是身份标记，但前后写实料包是碎纸、塑料和真实绑线，视觉上仍像不同物体。
- 从机械段切回S07写实结果图时，观众会感到从教学动画突然返回广告图，而不是同一包物料穿越两种表现层。
- 顶部概念说明在联系表中尺寸很小，无法承担足够醒目的“结构未验证”告知功能。

v002不应删掉机械段，而应为其建立明确的“概念剖切层”：用同一机位、相近光线、相同料包纹理和进入/退出匹配，让观众理解这是对真实镜头的解释，而不是素材替换。

## 4. 字幕可读性

### 主标题：静态抽帧中基本可读

- 白色大标题与暗色或复杂背景之间有足够对比，字号在联系表中可辨。
- 文字短、语义直接，适合竖屏移动端。

### 风险

- 左下角大标题位置接近短视频平台说明文字与操作区，需按目标平台安全区复核。
- 蓝绿色小标签字号偏小，在复杂物料背景上可能难读。
- 机械段顶部免责声明过小、过靠上；即使技术上存在，也很可能无法被普通观众读到。
- 每段字幕均采用类似位置与层级，会加强模板感。
- 未连续看片，无法确认字幕入场速度、停留时间、运动模糊和切镜前是否完整读完。

## 5. 官网快切素材质量落差

**风险高。**

render report显示40–45秒连续使用四张官网图片，每张1.25秒。联系表中的官网素材与生成图相比，分辨率、曝光、色彩、现场整洁度、机位和设备类型均存在明显差距。它们可以作为“真实来源证据”，但当前编排更像临时素材集锦：

- 从统一电影调色突然切到普通现场照片，会显著降低质感。
- 不同设备、厂房与料包可能被误读为同一机型、同一生产线或同一次拍摄。
- 低质量素材经过1080×1920放大后，噪点、模糊和压缩痕迹会更明显。
- 1.25秒不足以让观众辨认设备差异，却足以感知质量下降。

如果保留，应统一裁切、颜色、颗粒、边框/版式和运动，并明确它们是“真实项目/现场片段”而非同一镜头连续过程。更好的做法是只选1–2张质量最高、与目标机型最接近的官网素材。

## 6. 声音支撑

**无法完成主观通过判断。**

render report仅能确认存在“程序化临时工业音乐床 + v006临时机械声音”。这说明粗剪不是无声占位，但不能证明声音已经支撑55秒叙事。

需要重点验证：

- 0–17秒静态画面是否通过声音建立递进，而不是只有持续底噪；
- 17秒进入Blender时，声音是否自然接管而非突然变成教学演示；
- 压缩峰值、门启动、门停止、压板再次推进和料包离开是否逐一对齐；
- 33秒回到写实结果时，机械声是否延续空间感；
- 40–45秒快切是否有节奏依据，还是仅靠切图；
- 51–55秒是否有清晰收束，而不是音乐直接衰减。

临时声音可继续用于内部评审，不能作为正式声音交付。

## 7. 事实与误导风险

1. 17–33秒机械段来自v006概念预演，内部结构、压板行程、门、推出逻辑、绑扎与安全机制均未验证。
2. 生成写实图会被观众当成真实厂房和真实设备照片，尤其当前画面没有持续、醒目的概念标识。
3. 官网照片可能属于不同机型、不同客户现场与不同材料，快切会制造“同一设备完整案例”的错觉。
4. “从现场，到交付”容易把生成图也纳入真实现场证据链，需要区分实拍与概念视觉。
5. “把体积，变成效率”可以作为品牌表达，但当前没有产能、压缩比、节能或成本数据支持，不得扩写为量化承诺。
6. Logo、型号、参数、认证和CTA仍未确认，不宜在v001基础上推导或自动生成。

## v002三项最高优先级

### 1. 重构节奏，减少静态页

把0–17秒压缩至约10–12秒，每张图必须加入有叙事意义的局部运动或同一物料匹配；把33–40秒结果图缩至3–4秒；将释放出的时间用于机械段前后的动作桥接。整体节奏应形成“建立问题 → 加速进入流程 → 机械峰值 → 结果释放 → 品牌收束”。

### 2. 统一写实段与Blender段的视觉合同

用同一料包纹理、蓝红碎片、绑线、机位方向和光线方向连接S03→机械段→S07；为Blender段增加明确但不干扰阅读的“概念结构可视化”标识；进入和退出都采用形状/运动匹配，避免硬切成教学动画。

### 3. 收缩并重制官网快切

只保留1–2个与目标机型、材料和叙事最相关的真实素材；统一裁切、调色、清晰度和屏幕运动，并明确标注“真实现场素材”。如果素材无法达到主体画质，就使用短暂证据窗口或设计化胶片框，不让低清图片全屏占据5秒。

## 通过范围

- **通过：** 55秒宏观故事顺序、机械段作为中部核心、竖屏主标题的基本信息层级。
- **有条件通过：** v001作为v002剪辑结构底稿、临时声音和官网素材作为内部占位。
- **不通过：** 当前版本对外交付、整体电影连续性、写实与Blender风格衔接、官网素材统一性、事实边界和正式声音。

最终结论：**REJECT当前交付，保留为v002结构底稿。**
