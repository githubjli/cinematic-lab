# 金耐力工业宣传片测试方案 v001

更新日期：2026-10-21。目标是用一个真实工业产品案例验证本项目的宣传片生产流程。本文是制作方案，不代表品牌方确认，也不构成付费生成授权。

## 1. Brief与事实边界

官网当前把产品定义为废品/废纸液压打包设备，公开产品类别包括全自动、半自动、综合型废料压缩机和工厂专用机型；公开应用物料涉及废纸、塑料、薄铁皮、编织袋、旧衣物等。官网为“全自动250型”标注了12吨/小时、1100–1300 kg/包和可调打包尺寸等参数。以上只是网页声明，正式进入画面前须由品牌方提供最新产品手册或签字确认。

建议目标受众：再生资源回收站、分拣中心、造纸厂、塑料加工厂的设备采购和生产负责人。最终投放渠道、目标市场、语言、主推机型、询盘动作和预算均为未知。

片子的核心承诺暂定为：**把松散、占地、难运输的废料，稳定压成规整料包。** 视觉核心是从“无序体积”到“标准单元”的变化；品牌主张“简单、可靠、高效”作为收束，不把未经证实的规模、排名、节能比例或故障率写入旁白。

## 3. 创意结构

工作标题：**《把体积，变成效率》**。

1. **问题，0–8秒**：松散废料占据空间，画面中的体积网格不断膨胀；不使用夸张的“成本损失”数字。
2. **产品，8–15秒**：真实设备英雄镜头与简化线框叠合，品牌和主推机型第一次出现。
3. **机制，15–30秒**：上料、液压压缩、捆扎/出包。用真实视频证明设备在工作，用Blender剖切或透明代理解释受力和行程。
4. **结果，30–38秒**：料包规整、堆放和装运，表现空间被重新组织。压缩比例只在实测数据到位后出现。
5. **适配，38–46秒**：材料与机型矩阵，表达全自动/半自动/综合型/工厂专用的选型关系。
6. **交付，46–51秒**：把官网七步定制流程压缩为“分析现场—匹配方案—生产质检—售后服务”。
7. **收束，51–55秒**：品牌、主张、确认后的CTA。

镜头级文本和证据状态见`shotlist-v001.csv`。

## 4. 画面系统

- 主色从官网蓝色取样后建立正式色卡，辅以液压油金黄、设备金属灰和安全警示色；当前没有品牌色值文件，不能把网页CSS颜色直接当最终规范。
- 字体只选有明确商业授权的中文无衬线字体，并保存字体文件名、版本和许可。设备铭牌与安全标签必须来自实拍或品牌方文件，禁止AI生成乱码。
- 主视觉语法是“散点/碎片 → 受约束路径 → 紧密矩形”。所有转场、字幕入场和声音事件都服务于这一语法。
- CG模型分三级：L0几何占位、L1外观代理、L2工程批准模型。没有CAD时只能做L0/L1，不能展示看似精确但实际虚构的油路、尺寸和安全结构。
- 工厂、设备、料包和操作人员以真实素材为事实层；AI只生成抽象材质、无品牌环境延展或概念风格帧，不用来伪造生产规模、客户案例、认证和设备性能。

## 6. 制作流程与门禁

### P0 事实与权利锁定

品牌方提供：主推机型、最新参数表、Logo矢量文件、品牌规范、设备CAD/三视图、工厂与客户素材授权、操作安全要求、售后覆盖、CTA。把每条文案映射到一个证据文件；无法确认的字段保持“未知”，不靠官网营销句补齐。

### P1 资产体检

FFmpeg统一探测所有视频，生成代理、接触表和SHA256；照片记录原文件、来源、拍摄时间、作者和授权。CAD建立部件树，至少区分机架、压缩腔、主油缸、料门/出包、输送机和安全护罩；不确定的内部结构不进入剖视。

### P2 风格与动画预演

先用Blender灰模验证相机、行程、压缩节拍和横竖屏安全区，再做3套风格帧。D2动态分镜只用代理素材和临时声音，锁定55秒信息密度与镜头长度。

### P3 最难镜头Demo

制作S04–S06：真实上料切入CG结构解释，再切回真实出包。Demo至少比较两个方案：A为纪实主导、CG只解释；B为CG主导、真实镜头作证据。固定同一旁白和音轨盲评，选择信息更清楚且机械可信的方向。

门槛：总分≥85/100、每项≥75，且没有事实、权利、机械穿插、品牌错误、掉帧、音画漂移等硬失败。未通过只返修对应层，不整片重做。

### P4 全片与声音

按通过的视觉系统扩展10个镜头；配乐只用一条连续底，不随镜头重启。同期机械声构成低频重量，液压阀、压板接触、捆扎和料包落位各有独立事件音；避免每个MG动作都配“嗖”声。对白/旁白压混后测试手机外放仍清楚。

### P5 独立审评与交付

制作人与评审分离。评审只接收候选哈希、原始brief、固定参考集和`docs/mg-award-quality-gate-v001.md`，不接收提示词、制作解释或历史评分。最终母版目标≥90/100，概念、视觉系统、动画工艺各≥85；分数只能标记为内部候选，不能声称获奖或入围。

技术验收包括：完整解码、时长、24fps、色彩空间、音轨、响度、真峰值、字幕安全区、横竖屏逐版检查。视觉抽帧通过不能替代连续运动和声音审查。

## 7. 建议的首轮执行顺序

1. 向品牌方收集P0清单，并确定主推机型是否为全自动250型。
2. 将已有实拍和CAD复制到本项目的非Git素材区，生成哈希与接触表。
3. 以S04–S06建12秒灰模预演；不调用生成模型。
4. 用3套风格帧确定“真实/CG/MG”的比例。
5. 完成两个D3版本，交独立评审；只让通过方向进入全片。
6. 锁定旁白、声音和EDL，再输出55秒9:16母版；母版通过后另编20秒9:16短版。
